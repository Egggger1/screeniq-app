## 技术路线（为什么这么设计）

| 模块 | 做法 | 好处 |
|------|------|------|
| 界面 | WebView 直接加载打包进 APK 的网页 | 复用电脑版做好的 Material 3 界面，不用重画 |
| 数据衔接 | JS 适配层把 `fetch('/api/*')` 转发给原生桥接 | 网页业务代码一行没改 |
| 中文识字 | ML Kit standalone 版，模型打进 APK | **荣耀手机没谷歌服务也能用**，离线可识别 |
| AI 答题 | OkHttp 直连大模型接口，4 个模型可选 | 跟电脑版逻辑一致，带假答题兜底 |
| 密钥 | SharedPreferences 存本机，回显打码 | 不上传、不回显明文 |
| 权限 | 只申请 INTERNET | 最少权限，符合项目定位 |

## 怎么编译出 APK（等仓库问题解决后）

1. 在 GitHub 网页手动建一个空仓库（比如 `screeniq-app`）
2. 把本目录源码推上去
3. GitHub Actions 会自动跑 `.github/workflows/build.yml`，产出 `app-debug.apk`
4. 从 Actions 的 artifact 下载 APK，传到荣耀手机安装

## 给荣耀手机安装

- 安装时系统会提示"未知来源应用"，选允许（Debug 包没上架应用市场，属正常）
- 装好后打开 App：点📷上传题目图片 → 自动识别 → 出答案
- 想用真模型：点右上角 ⚙ 填 DeepSeek 的 API Key（界面里有免费申请链接）；
  不填也能用，会走假答题演示
