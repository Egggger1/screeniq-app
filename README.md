## 给荣耀手机安装（安卓 MagicOS，不是鸿蒙）

1. 把 `屏知ScreenIQ-v0.1.apk` 传到手机（微信/QQ 发文件、或数据线拷贝都行）
2. 手机上点开这个 APK → 系统提示"未知来源应用"→ 选**允许**
   （Debug 包没上架应用市场，这个提示是正常的）
3. 装好后打开 App：点 📷 上传题目图片 → 自动识别 → 出答案
4. 想用真模型：点右上角 ⚙ → 选 DeepSeek → 填 API Key（界面里有免费申请链接）
   不填也能用，会走假答题演示

## 界面里能做什么

| 功能 | 说明 |
|------|------|
| 识屏答题 | 上传题目截图 → 离线中文识别 → 出答案，不用联网也能识字 |
| 自由聊天 | 侧栏切换，直接打字提问，和识屏共用同一套模型 |
| 详细解释开关 | 输入框上方芯片，「开」给答案+步骤，「关」只给答案 |
| 多模型聚合 | DeepSeek / Kimi / 通义 / OpenAI，右上角切换 |
| 密钥本地存 | SharedPreferences 只存本机，回显打码，不上传 |

## 技术路线（为什么这么设计）

| 模块 | 做法 | 好处 |
|------|------|------|
| 界面 | WebView 加载打包进 APK 的网页 | 复用电脑版做好的 Material 3 界面，不用重画 |
| 数据衔接 | JS 适配层把 `fetch('/api/*')` 转发给原生桥接 | 网页业务代码一行没改 |
| 中文识字 | ML Kit standalone 版，模型打进 APK | 荣耀手机没谷歌服务也能用，离线可识别 |
| AI 答题 | OkHttp 直连大模型接口，4 个模型可选 | 跟电脑版逻辑一致，带假答题兜底 |
| 权限 | 只申请 INTERNET | 最少权限，符合项目定位 |
