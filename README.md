# 屏知 ScreenIQ · 安卓版

手机端读屏答疑 App：**后台读屏 → AI 作答 → 答案浮在屏幕上 → 自动点选**。
全部开关都在用户手里，默认不自动点，需要自己打开。

## 当前版本：v0.3.0

| 项 | 说明 |
|----|------|
| 触发 | 页面变化自动触发 + 每 1.5 秒指纹巡检，不用手点 |
| 读字 | ① 无障碍节点文字 ② 截图 + 本机离线中文识别（带每行坐标）③ 需要认图时交视觉模型 |
| 答题 | OkHttp 直连 OpenAI 兼容接口：DeepSeek / Kimi / 通义 / OpenAI |
| 显示 | 顶部悬浮答案卡，30 秒自动收成右侧小胶囊 |
| 点选 | 三条路线：无障碍节点 → 识别框坐标 → 模型给的坐标，都不中就说原因，不瞎点 |
| 入口 | 常驻悬浮球：⚡识屏作答 / ◎自动作答开关 / 暂停 / 面板 |
| 包体 | 只打 arm64-v8a；约 18MB（上一版四 ABI 全带 50MB） |

## 装到荣耀手机（MagicOS，不是鸿蒙）

1. 把 APK 传到手机（微信/QQ 发文件、数据线都行），点开 → 允许"未知来源"
2. 打开 App，按面板上的一二三步走：
   - ① 开启读屏权限（系统设置里找到「屏知 ScreenIQ」打开）
   - ② 开启悬浮窗权限
   - ③ 打开「自动识屏」开关
3. 面板里填 API Key（只用 DeepSeek 也行，只是认不了生僻字）
4. 退出 App，屏幕右侧挂一粒「屏知」胶囊 → 切到题目页就会自己读

## 为什么自动点选要三条路线

| 页面类型 | 节点树有文字吗 | 靠什么点中 |
|----------|----------------|------------|
| 原生 App 题目（学习通等） | 有 | 无障碍节点 ACTION_CLICK |
| H5 / 活动答题（选项是 Canvas 画的） | 没有 | 截图识别出的**文字框坐标** → 手势注入 |
| 整题一张图、字也认不出 | 没有 | 视觉模型返回的相对坐标 `POINT:x,y` |

第一版只做了第一条，所以在拼多多那种"画上去的选项"页面上，答案能显示、却永远点不动。
v0.3.0 补的正是第二条——**识别不只给文字，还给每行字的坐标**。
