# 屏知 ScreenIQ · 安卓版

手机端读屏答疑 App：**后台读屏 → AI 作答 → 答案浮在屏幕上 → 自动点选**。
全部开关都在用户手里，默认不自动点，需要自己打开。

## 当前版本：v0.6.0（字母锚点 + 多选防漏选）

| 项 | 说明 |
|----|------|
| 触发 | 无障碍事件 + 每 1.2 秒**像素指纹巡检**（页面变了就重读，换题不漏）；三入口共用一个闸门，不会两轮并行 |
| 读字 | ① 无障碍节点文字（跳过密码框）② 每轮截图 + 本机离线中文识别（带每行坐标）③ 需要认图时交视觉模型 |
| 答题 | 可取消的 OkHttp 请求，直连 DeepSeek / Kimi / 通义 / OpenAI；答案强制带 `ANS:字母`，单选一个、多选多个 |
| 显示 | 顶部悬浮答案卡，30 秒自动收成右侧小胶囊 |
| 点选 | **选项字母锚点（最可靠）** → 可点控件编号(E) → 模型截图编号 → 无障碍节点 → 识别框坐标 → 模型坐标；字母支持 Ⓐⓐ／(A)／全角／独立圆圈行 |
| 多选 | 逐个字母依次点亮、逐个截图确认；**有一个没点中就不跳题**，绝不漏选进下一道 |
| 推进 | 全部选完后才按「下一题 / 继续答题 / 领取奖励」白名单按钮；「确定/好的/领取」已移出，避免误点弹窗 |
| 隐私 | 密钥 Keystore 加密且与日志分文件、禁止备份；日志只记长度和哈希，不记题目原文 |
| 入口 | 常驻悬浮球：⚡识屏作答 / ◎自动作答开关 / 暂停 / 面板 |
| 包体 | arm64-v8a + armeabi-v7a；约 24MB |

## 装到荣耀手机（MagicOS，不是鸿蒙）

1. 把 APK 传到手机（微信/QQ 发文件、数据线都行），点开 → 允许"未知来源"
2. 打开 App，按面板上的一二三步走：
   - ① 开启读屏权限（系统设置里找到「屏知 ScreenIQ」打开）
   - ② 开启悬浮窗权限
   - ③ 打开「自动识屏」开关
3. 面板里填 API Key（只用 DeepSeek 也行，只是认不了生僻字）
4. 退出 App，屏幕右侧挂一粒「屏知」胶囊 → 切到题目页就会自己读

## 为什么自动点选要三条路线

| 页面类型 | 节点树有文字吗 | 靠什么点中 |
|----------|----------------|------------|
| 原生 App 题目（学习通等） | 有 | 无障碍节点 ACTION_CLICK |
| H5 / 活动答题（选项是 Canvas 画的） | 没有 | 截图识别出的**文字框坐标** → 手势注入 |
| 整题一张图、字也认不出 | 没有 | 视觉模型返回的相对坐标 `POINT:x,y` |

第一版只做了第一条，所以在拼多多那种"画上去的选项"页面上，答案能显示、却永远点不动。
v0.3.0 补的正是第二条——**识别不只给文字，还给每行字的坐标**。
v0.4.0 又修了三个把整题吞掉的 bug：指纹被截断成前 400 字（换题后看起来没变）、
"节点够用就不截图"（可题干偏偏画在图上）、巡检传 `allowOcr=false`（发现了变化却拒绝看图）。

## 自动作答这条链路怎么保证不点错

1. 定位按"准→糙"排：**选项字母锚点** → 控件编号 → 截图编号 → 节点精确 → 识别精确 → 模型坐标。**自动作答下不走模糊包含**，手动点选才允许。
2. 为什么字母排第一：模型常把选项文字改写（屏幕写"人自我值和社会值互相区别"，答案写"自我价值和社会价值互相区别"），文本匹配必失败；但选项前的 A/B/C/D 字母不会变。v0.6.0 让模型直接给 `ANS:字母`，按字母点，绕开措辞差异。
3. 字母识别兼容题库里"单独一个圆圈字母 Ⓒ 在左、文字在右"的排版：找到字母行后取同一水平带的文字行作为落点；也认 Ⓐⓐ／(A)／Ａ 全角／A. 等写法。模型忘了写 ANS 时，从答案首行兜底抽字母。
4. 候选词只取模型答案的**第一行**，解析文字不参与点击决策——否则"苏州是错误选项"会变成可点目标。
5. 危险控件黑名单（支付/授权/发送/删除…）+ 模型坐标必须落在题目区域，挡住提示词注入。
6. 点之前先看**选项词集合**有没有整体换掉（换题了就放弃这次点选）；选项不足时退回像素比对。
7. 点之后截一屏比对；没变化就在**同一个点**用真实触摸补一次，仍不动才换落点，且换之前再核一次页面指纹。
8. **多选与防漏选**：模型给 2 个以上字母就走多选执行器——每个字母重新按锚点定位、逐个点亮、逐个截图确认。连点期间只用"选项文字集合"判断换题（选中高亮会改像素，不能用像素判断，否则点完第一个就误判换题而漏掉其余）。只要有一个没点中，就明确"漏选"并**故意不点下一题**，停在本题等你处理。
9. 同一屏累计点不动 2 次就熔断停手，不再乱戳、不再重复烧 token。
10. 结果写在答案卡标题上，日志带坐标和摘要（不记题目原文）。
